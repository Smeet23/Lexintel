## RESEARCH LIMITATIONS

### What We Don't Know (Competitive Secrets)
1. **Exact embedding models used:**
   - Harvey confirmed Voyage partnership but other details proprietary
   - CoCounsel uses Claude embeddings but not disclosed publicly
   - Luminance's LPT training data composition unknown

2. **Internal hallucination rates:**
   - Only publicly available data: Stanford 2025 (Lexis+, Westlaw, general tools)
   - Harvey, CoCounsel, Luminance don't disclose internal benchmarks

3. **Exact architecture details:**
   - Harvey's retrieval pipeline "Part 2 coming soon" (as of research date)
   - CoCounsel's Deep Research agent system is public but implementation details sparse

4. **Cost/Performance tradeoffs:**
   - Long-context pricing varies by provider
   - True ROI metrics not disclosed by any vendor

### Methodology Limitations
1. **Web search bias:** Recent products (2025-2026) over-represented; older products underrepresented
2. **Press release bias:** Products emphasize strengths; weaknesses not disclosed
3. **Academic lag:** Best practices papers lag commercial implementation by 6-12 months
4. **Incomplete information:** Some products (e.g., Westlaw AI) have limited public technical documentation

### Recommendations for Future Research
1. **Direct product testing:** Run benchmark tests against published accuracy metrics
2. **Customer interviews:** Real law firm usage data (not vendor claims)
3. **Security audits:** Validate zero-access, encryption, data protection claims
4. **Cost modeling:** True cost per use case (not just list pricing)
